# Lighter — handoff

Состояние на 16.10.2026, версия **1.0.0** (тег `v1.0.0`).

## Что это

Менеджер автозагрузки Windows в одном `.exe` (~150 КБ): реестр Run/RunOnce, папки «Автозагрузка»,
задачи планировщика (вход/загрузка), службы с автозапуском, список процессов.
Вкл/выкл, удаление с резервной копией, тёмная/светлая тема, RU/EN, плавные анимации.

## Сборка и релиз

- `build.cmd` — собирает `bin\Lighter.exe` встроенным в Windows компилятором
  (`%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`). SDK и Visual Studio не нужны.
  Сначала собирается `tools\MakeIcon.cs` и генерирует `obj\app.ico` из `src\Logo.cs`.
- Релиз: поднять версию в `src\AssemblyInfo.cs` → коммит → `git tag vX.Y.Z` → `git push origin vX.Y.Z`.
  `.github/workflows/release.yml` соберёт exe и создаст GitHub Release с `Lighter.exe` и `.sha256`.
  На обычный push в `main` и на pull request workflow только собирает (артефакт без релиза).
- `bin/`, `obj/`, `*.exe` в git не попадают (`.gitignore`).

## Что проверено, а что нет

Проверено без прав администратора: чтение всех источников; вкл/выкл/удаление/резервная копия
для HKCU Run и пользовательской папки «Автозагрузка»; завершение процесса; обе темы и оба языка
(скриншоты); ровность кадров (60 fps, p95 16,7 мс); отсутствие утечек GDI/дескрипторов
(40 переключений вкладок + 4 смены темы).

**Не проверено:**
- вкл/выкл/удаление задач планировщика и вкл/выкл служб — нужен запуск от администратора;
- HKLM-записи и общая папка «Автозагрузка» — нужен администратор;
- анимации глазами на живом экране (скриншоты статичны);
- результат первого прогона GitHub Actions для `v1.0.0`.

Тестовых проектов в репозитории нет — проверки делались временными утилитами (см. «Как проверять»).

## Устройство (`src/`)

|---|---|
| `Program.cs` | Точка входа: DPI, `L.Init()`, `Theme.Init()`, глобальный обработчик ошибок |
| `MainForm.cs` | Окно: вкладки, панель действий, загрузка данных, действия, клавиши, `ApplyLanguage()` |
| `AutorunItem.cs` | Модель записи; `StateText`/`Location` вычисляются на текущем языке; `Autoruns` — диспетчер вкл/выкл/удаления |
| `RegistryRunSource.cs` | Run/RunOnce в HKCU/HKLM/WOW6432Node |
| `StartupFolderSource.cs` | Папки «Автозагрузка», разбор `.lnk` через WScript.Shell |
| `TaskSchedulerSource.cs` | Планировщик: один COM-вызов (`Xml`) на задачу, текстовый фильтр триггеров |
| `ServiceSource.cs` | Службы; исходный тип запуска отключённых хранится в `HKLM\SOFTWARE\Lighter\DisabledServices` |
| `ProcessList.cs` | Процессы, путь через `QueryFullProcessImageName`, пометка «из автозапуска» |
| `StartupApproved.cs` | Флаги вкл/выкл как в Диспетчере задач (`…\Explorer\StartupApproved`) |
| `Backup.cs` | Резервные копии в `%LOCALAPPDATA%\Lighter\Backup` (`.reg`/`.lnk`/`.xml`) |
| `Com.cs` | Позднее связывание COM через IDispatch (замена `dynamic`) |
| `Native.cs` | P/Invoke: службы, путь процесса, иконки, `SetWindowTheme` |
| `PathUtil.cs` | Путь к exe из командной строки, издатель (с кэшем) |
| `Theme.cs` | Палитры, шрифты, DPI-масштаб `S()`, тёмный заголовок окна |
| `Lang.cs` | RU/EN: строки парами `L.T("рус", "eng")` прямо в коде |
| `Anim.cs` | Движок анимаций: отдельный поток-часы, кадры по vblank (локально) или 60 Гц (RDP) |
| `Transition.cs` | Плавная смена содержимого: снимок «до» сверху, смена под ним, смешивание GDI AlphaBlend |
| `Controls.cs` | Свои контролы: кнопки, вкладки, переключатели, поиск, полоса загрузки, уведомления |
| `ListViewEx.cs` | Owner-draw ListView: тема, иконки, статус-точки, анимации строк |
| `Dialogs.cs` | Свои диалоги вместо MessageBox, тематическое контекстное меню |
| `Logo.cs` | Логотип (кольцо, фиолетовый на тёмно-сером) и сборка `.ico` |

## Решения и причины

- **.NET Framework 4.8 + встроенный csc** — один exe без установки на любой Windows 10/11/Server 2016+.
  Цена: синтаксис **C# 5** (нет `$""`, `?.`, `nameof`, expression-bodied членов).
- **Без `dynamic`** — он тянет Microsoft.CSharp и DLR (память и время запуска); COM через `Com.cs`.
- **Вкл/выкл через StartupApproved** — обратимо и совпадает с Диспетчером задач. RunOnce переключить нельзя (только удалить).
- **Службы не удаляются**, только отключаются — слишком опасно.
- **Списки не докуются**, размер задаётся вручную всем (и скрытым): докинг пропускает скрытые контролы,
  и заполненный в скрытом виде список получал «залипшие» полосы прокрутки.
- **Ленивая отрисовка**: при изменении данных/поиска/языка перестраивается только видимый список, остальные помечаются `dirty`.
- **Загрузка параллельная**: каждый источник в своём STA-потоке; иконки процессов извлекаются в том же потоке, что и процессы.
- **Часы анимаций**: таймер WinForms шагает по 15,6 мс неравномерно. В RDP DWM сообщает ~32 Гц —
  там намеренно ровные 60 Гц без привязки к vblank.
- **Переходы**: «до» показывается поверх сразу, изменение делается под ним — так нет мигания.
  Повторный переход на ту же цель продолжает с текущего кадра.
- **Окно после появления** снимает `WS_EX_LAYERED` (`AllowTransparency = false`) — обычная отрисовка быстрее.

## Подводные камни

- В исходниках глифы Segoe MDL2 иногда записаны **реальными символами** из Private Use Area, а не `\uXXXX`.
  Редакторы и инструменты могут показывать их пустыми — правьте такие строки осторожно.
- Снимки для переходов делаются через `WM_PRINT`; всё, что рисуется только в `WM_PAINT`,
  нужно рисовать и в `WM_PRINTCLIENT` (так сделано для текста пустого списка).
- Без прав администратора часть путей служб и процессов не читается — это не ошибка.
- PowerShell 5.1 пишет UTF-8 с BOM: сообщения коммитов из файла сохранять без BOM.
- Git Credential Manager в неинтерактивной среде (`GCM_INTERACTIVE=never`) не покажет окно входа —
  для `git push` нужна интерактивная сессия.

## Как проверять

1. `build.cmd` без ошибок.
2. Запуск от администратора: на тестовых записях проверить вкл/выкл/удаление в каждом источнике:
   - `reg add HKCU\Software\Microsoft\Windows\CurrentVersion\Run /v LighterTest /d notepad.exe`
   - ярлык на notepad в `shell:startup`
   - `schtasks /create /tn LighterTest /tr notepad.exe /sc onlogon`
   - `sc create LighterTestSvc binPath= C:\Windows\notepad.exe start= auto`

   Убедиться, что состояние совпадает с Диспетчером задач / `schtasks /query` / `sc qc`, и что копии есть в Backup.
3. Переключение вкладок, тем и языка — без мигания; F5, поиск, Ctrl+A, Space, Del.
4. Удалить тестовые записи (`sc delete LighterTestSvc` и т. д.).
