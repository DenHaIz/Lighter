# Lighter

**Лёгкий менеджер автозагрузки Windows в одном .exe-файле.** Без установки и без скачивания среды выполнения — используется .NET Framework 4.8, встроенный в Windows.

## Возможности

- **Автозагрузка** — ключи реестра `Run` / `RunOnce` (HKCU, HKLM, 32-бит) и папки «Автозагрузка».
- **Планировщик** — задачи, запускаемые при входе или при загрузке (системные скрыты по умолчанию).
- **Службы** — службы с автозапуском: отключение и последующее восстановление исходного типа запуска.
- **Процессы** — запущенные процессы с памятью и издателем; отмечены запущенные из автозагрузки; завершение процесса.
- **Вкл/выкл** работает так же, как в Диспетчере задач (`StartupApproved`), поэтому состояние совпадает.
- **Удаление с резервной копией** — перед удалением запись сохраняется (`.reg`, `.lnk` или `.xml` задачи) в `%LOCALAPPDATA%\Lighter\Backup`; для восстановления достаточно открыть файл.
- Тёмная и светлая темы, русский и английский интерфейс, плавные анимации, поиск и сортировка.

## Скачать

`Lighter.exe` — в разделе [Releases](../../releases). Для каждого релиза указана контрольная сумма SHA-256.

Программа запрашивает права администратора (UAC): они нужны для HKLM, служб и системных задач.
Файл не подписан сертификатом, поэтому SmartScreen при первом запуске может показать «Неизвестный издатель».

**Требования:** Windows 10 / 11 или Windows Server 2016+ (.NET Framework 4.8 встроен).

## Клавиши

| Клавиша | Действие |
|---|---|
| Space | Включить / отключить выбранные записи |
| Del | Удалить запись / завершить процесс |
| F5 | Обновить |
| Ctrl+F | Поиск |
| Ctrl+1…4 | Переключение вкладок |

## Что Lighter меняет в системе

| Действие | Где |
|---|---|
| Вкл/выкл записи реестра или папки «Автозагрузка» | `…\Explorer\StartupApproved\Run`, `Run32`, `StartupFolder` (как Диспетчер задач) |
| Вкл/выкл задачи планировщика | флаг *Enabled* задачи |
| Отключение службы | тип запуска → *Отключена*; исходный тип хранится в `HKLM\SOFTWARE\Lighter\DisabledServices` |
| Удаление | копия в `%LOCALAPPDATA%\Lighter\Backup`, затем запись удаляется |
| Настройки (тема, язык) | `HKCU\Software\Lighter` |

## Сборка из исходников

SDK и Visual Studio не нужны — достаточно компилятора C#, который есть в Windows:

```
build.cmd
```

Результат — `bin\Lighter.exe`. Иконка exe генерируется при сборке тем же кодом, что рисует логотип в приложении (`src\Logo.cs`, `tools\MakeIcon.cs`).
